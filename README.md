# Пиксельный штаб

Учебный проект — панель управления школьным киберклубом с библиотекой игр и лентой скидок.

🌐 [Посмотреть проект](https://iamschikov.github.io/gamingsearch/)

## Стек
Чистые HTML, CSS и JavaScript. Без фреймворков, сборщиков и внешних библиотек.

## Что умеет
- Адаптируется под экраны телефонов, планшетов и компьютеров.
- Показывает список игр из массива данных.
- Отображает сообщение, если библиотека пуста.
- Поддерживает навигацию с клавиатуры и читаемость для скринридеров.

## Что сделано с помощью ИИ
- Каркас index.html, стили style.css и скрипт script.js написаны моделью Qwen по моим промптам.
- Я прочитал код, разобрал его построчно и проверил работу в браузере.
- Сообщения коммитов сформулированы по правилам курса и проверены вручную.
